# ربات کوییز الهوریس 🔮✨

فقط دو فایل، بدون هیچ Dependency خارجی (فقط کتابخانه استاندارد پایتون -
`sqlite3` و `urllib`) - نصبش روی گوشی/Termux به همان راحتی سرور است.

## چی عوض شده (نسخه‌ی فعلی)

- ❌ **آزمون جامع رندوم حذف شد.** به‌جایش هر بخش («ورکشاپ» و «ترم اول») یک
  مبحث ویژه‌ی خودکار به اسم **«کل ورکشاپ»** / **«کل ترم اول»** دارد. هر سؤالی
  که به هر مبحثی اضافه کنید، خودکار یک کپی از آن هم در همین مبحث آرشیوی
  ذخیره می‌شود. برای آزمون کلی نهایی، کافی است یک کوییز روی همین مبحث
  آرشیوی برگزار کنید - همان کاری که آزمون جامع قبلاً انجام می‌داد.
- 🏷 نام بخش‌ها عوض شد: «ترم‌های قبلی» → **🪄 ورکشاپ**، «ترم اولی‌ها» →
  **🔮 ترم اول**.
- 🎲 سؤالات همه‌جا (نه فقط در آرشیو) **همیشه به‌صورت رندوم** پرسیده می‌شوند،
  نه به ترتیب اضافه‌شدن.
- 🔢 موقع ساخت کوییز، علاوه بر زمان هر سؤال، **تعداد سؤال** هم انتخاب می‌شود:
  ۱، ۵، ۱۰، ۱۵ یا ۲۰ سؤال. با انتخاب هرکدام، کنار دکمه‌اش ✅ می‌خورد.
- 🧮 سیستم نمره‌دهی جدید (هر حالت طوری طراحی شده که با جواب‌های درست و
  سریع، جمع نمرات به ۲۰ برسد):

  | تعداد سؤال | نمره‌ی هر سؤال | جریمه‌ی دیرجواب‌دادن |
  |---|---|---|
  | ۱ | ۲۰ | پیوسته، ۱ تا ۸ نمره بسته به سرعت |
  | ۵ | ۴ | ۰ (سریع) / ۰.۵ (متوسط) / ۱ (دیر) |
  | ۱۰ | ۲ | ۰ / ۰.۵ / ۱ |
  | ۱۵ | ۲۰÷۱۵ | ۰ / ۰.۲۵ / ۰.۵ |
  | ۲۰ | ۱ | ۰ / ۰.۲۵ / ۰.۵ |

  «سریع» یعنی جواب دادن در یک‌سومِ اول زمانِ مجاز آن سؤال، «دیر» یعنی
  یک‌سومِ آخر.
- 👤 **چند ادمین همزمان**: از پنل («👤 مدیریت ادمین‌ها») می‌توانید ادمین
  اضافه/حذف کنید، بدون نیاز به ویرایش `.env` و ری‌استارت ربات. ادمین‌های
  داخل `.env` («ثابت») همیشه معتبرند و از داخل ربات قابل حذف نیستند.
- 🔒 فقط ادمین‌ها/استاد به مباحث، سؤالات و هر بخش مدیریتی دسترسی دارند؛
  بقیه فقط پیام خوش‌آمد و دکمه‌های شرکت/پاسخ در کوییزهای فعال را می‌بینند.
- ✨ لحن و ایموجی‌ها عوض شد (حس جادویی‌تر، غیررسمی‌تر).

## نصب روی Termux

```bash
pkg update && pkg install python -y
mkdir -p ~/quizbot && cd ~/quizbot
# db.py و bot.py را همین‌جا کپی کنید

cp .env.example .env
nano .env    # BOT_TOKEN و ADMIN_IDS را پر کنید

python bot.py
```

اجرای دائمی در پس‌زمینه:

```bash
pkg install tmux -y
tmux new -s quizbot
cd ~/quizbot && python bot.py
# Ctrl+B سپس D برای خروج بدون قطع شدن ربات
# tmux attach -t quizbot برای برگشتن
```

## نحوه استفاده

۱. در گروه `/admin` بزنید (فقط ادمین‌ها این پنل را می‌بینند).
۲. **مدیریت مباحث** → بخش (ورکشاپ/ترم اول) → مبحث اضافه/ویرایش کنید. مبحث
   آرشیوی («کل ورکشاپ»/«کل ترم اول») همیشه آماده است و قابل حذف نیست.
۳. **مدیریت سوالات** → مبحث → سؤال بسازید (متن → گزینه A تا D → گزینه
   درست). هر سؤال خودکار در آرشیو هم ذخیره می‌شود.
۴. **برگزاری کوییز** → بخش → مبحث → روی صفحه‌ی بعد هم **زمان هر سؤال** و
   هم **تعداد سؤال** را انتخاب کنید (هرکدام که بزنید کنارش ✅ می‌خورد) →
   «🚀 شروع کوییز».
۵. دانش‌آموزان «🎮 شرکت در کوییز» می‌زنند؛ وقتی حداقل یک نفر ثبت‌نام کرد،
   ادمین «▶️ شروع کوییز» را می‌زند.
۶. حین اجرا: «⏭ سؤال بعدی» / «⏸ توقف موقت» / «🛑 لغو کوییز».
۷. برای **آزمون کلی نهایی**: از «برگزاری کوییز» مبحث «کل ورکشاپ» یا
   «کل ترم اول» را انتخاب کنید - همه‌ی سؤالات هر دو بخش آنجا آرشیو شده‌اند
   و رندوم پرسیده می‌شوند.
۸. **👤 مدیریت ادمین‌ها**: آیدی عددی تلگرام فرد موردنظر را بفرستید تا ادمین
   شود (می‌تواند از @userinfobot آیدی‌اش را بگیرد).

## Backup دیتابیس

```bash
sqlite3 quiz.db ".backup 'backup_$(date +%Y%m%d_%H%M%S).db'"
```

## ⚠️ توجه مهم درباره‌ی ارتقا از نسخه‌ی قبلی

اگر از نسخه‌ی قبلی (با «آزمون جامع») یک فایل `quiz.db` دارید، ساختار
جدول‌ها عوض شده (ستون‌های نمره حالا اعشاری‌اند، ستون `is_archive` اضافه
شده، جدول ادمین‌ها اضافه شده). ساده‌ترین راه: قبل از اجرای نسخه‌ی جدید،
یک بک‌آپ از `quiz.db` قدیمی بگیرید و بعد خودش را حذف کنید تا از صفر و با
ساختار جدید ساخته شود:

```bash
mv quiz.db quiz_old_backup.db
python bot.py
```

## تست‌شده به چه شکلی؟

مثل نسخه‌ی قبلی، چون این پروژه فقط کتابخانه‌ی استاندارد پایتون استفاده
می‌کند، توانستم لایه‌ی HTTP تلگرام را جایگزین کنم و کل منطق واقعی
(`db.py` و `bot.py`) را در یک اسکریپت شبیه‌سازی واقعاً **اجرا** کنم، نه
فقط syntax-check. مواردی که اجرا و Assert شدند:

- تغییر نام بخش‌ها؛ ساخته‌شدن خودکار مبحث‌های آرشیوی.
- افزودن سؤال به یک مبحث عادی → کپی خودکار در آرشیو.
- محافظت از مبحث آرشیوی (تغییر نام/حذف/افزودن دستی سؤال، هرسه رد می‌شوند).
- کاربر غیرادمین از `/admin` و همه‌ی دکمه‌های مدیریتی رد می‌شود.
- متن استارت جدید دقیقاً همان‌طور که خواسته شده نمایش داده می‌شود.
- انتخاب همزمان زمان + تعداد سؤال با تیک ✅ روی دکمه‌ی انتخاب‌شده.
- وقتی مبحث سؤال کمتر از تعداد انتخابی دارد، هشدار صادقانه نمایش داده
  و تعداد واقعی به‌جایش استفاده می‌شود.
- فرمول نمره‌دهی هر ۵ حالت (۱/۵/۱۰/۱۵/۲۰ سؤالی) دقیقاً طبق جدول بالا
  محاسبه شد؛ جمع نمرات جواب‌های سریع و درست در هر حالت، ۲۰ شد.
- افزودن/حذف ادمین از پنل، و شناسایی‌شدن ادمین جدید توسط `is_admin()`.
- ادمین «ثابت» (از `.env`) از داخل ربات غیرقابل‌حذف است.

با این حال چون امکان تست با یک توکن واقعی تلگرام نبود، پیش از استفاده‌ی
واقعی یک تست کوتاه دستی با چند نفر در یک گروه تست توصیه می‌شود.
